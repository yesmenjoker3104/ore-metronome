# Ore Metronome

## プレイリスト

「プレイリスト」ボタンで、メトロノームの右側にプレイリストパネルを開きます。プレイリストの中に曲を並べて管理します。

- 「追加」で、現在の設定を曲として追加
- 曲の更新、削除。曲はダブルクリックで適用
- プレイリストと曲は、行をドラッグして並べ替え。各行の「↑」「↓」ボタンでも 1 つずつ動かせます

プレイリストは `%APPDATA%\ore-metronome\setlists.json` に保存されます。
曲には BPM、拍子、細分、位置マスク、アクセント、練習設定（テンポアップ、チェンジアップ、スウィング）など、その時点の設定が保存されます。
曲を適用しても音量は変わりません。
以前の版で保存した曲は「デフォルト」というプレイリストに移行されます。
プレイリストファイルが壊れている場合は、`setlists.json.bak` に退避して空の一覧で起動します。
現在のバージョンでは手動切替に対応しており、停止条件に連動した自動進行は今後の対応です。

## 練習設定

「練習設定」ボタンで、練習用の設定を開きます。画面は非表示にせず、メトロノームの横に開きます。

- テンポアップ: 指定した小節ごとに BPM を上げ下げします。下限・上限と、目標 BPM を指定できます。目標に達したら、次の変化の小節で開始の BPM に戻して繰り返します。
- チェンジアップ: 細分と小節数の組（段階）を順に進め、最後の段階の後は先頭に戻って繰り返します。既定は 4 分 × 4 → 8 分 × 4 → 3 連符 × 4 → 16 分 × 4 です。段階は追加・更新・削除、またはドラッグ・「↑」「↓」で並べ替えできます。
- スウィング: 50〜75%。8 分・16 分・32 分・6 連符の裏拍を遅らせます。50% が通常のリズムです。
- テンポアップとチェンジアップは同時に使えます。
- ダイアログ下部の「閉じる」ボタンで閉じます。
